# SEO, PWA et i18n : plan d'implémentation

> **Pour les agents :** sous-skill OBLIGATOIRE : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans pour exécuter ce plan tâche par tâche. Les étapes utilisent des cases à cocher (`- [ ]`).

**But :** référencement complet (métadonnées, sitemap, robots, JSON-LD, images OG), PWA installable avec page hors ligne, et structure i18n et évolutions.

**Architecture :**
- Conventions de fichiers de métadonnées de Next.
- Constructeurs purs et testés pour les URL et le JSON-LD (`lib/seo.ts`), pour la sélection du numéro par région (`lib/whatsapp-region.ts`) et pour les dictionnaires (`lib/i18n`).
- Un service worker écrit à la main.

**Stack :** Next.js 16.4, React 19.3, `node --test`, Playwright, Lighthouse (Chrome installé).

**Spec :** `docs/superpowers/specs/2026-11-21-seo-pwa-i18n-design.md`

## Contraintes globales
- Adresse : `siteConfig.siteUrl` (`NEXT_PUBLIC_SITE_URL`), repli `https://saqia.site`.
- Aucun prix, avis, note ou stock chiffré dans le JSON-LD ou les métadonnées.
- `/brand`, `/design` et `/admin` absents du sitemap et bloqués dans robots.
- Aucune dépendance. Commits en Conventional Commits français, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Lint, tsc et tests au vert avant chaque commit.

## Points de vigilance (Review Focus)
1. **Produit sans photo réelle** (image provisoire) : le JSON-LD n'expose pas le visuel provisoire comme photo du produit, et l'image OG s'affiche quand même. → test dans la tâche 3 (`productJsonLd` omet `image` si `imagePlaceholder`).
2. **Texte avec guillemets, `<` ou `</script>`** dans un nom ou une description : le JSON-LD reste valide et sûr. → test dans la tâche 3 (`jsonLdScript` échappe `<`).
3. **`NEXT_PUBLIC_SITE_URL` avec une barre finale ou sans protocole** : URL absolues correctes. → test dans la tâche 1 (`absoluteUrl`).
4. **Service worker après un déploiement** : pas de page périmée, nouvelle version prise sans action. → tâche 5 (`skipWaiting` + `clients.claim`, aucun cache de pages en dehors de `/hors-ligne` ; e2e : en ligne, `/` renvoie le contenu à jour).
5. **Région inconnue ou numéro de région invalide** : repli sur le numéro par défaut. → test dans la tâche 6.
